# stdplus

An extended standard library for Rust.

`stdplus` has two main goals:
* Be a viable implementation of common missing functionality from Rust's standard library.
* Be a fun learning project.

It also has the following subgoals to accomplish the above two:
* No third-party dependencies.
* Extensively tested.
